# NUS Medicine Top 10 Achievements Planner

A simple, browser-only planner for organising a student's Top 10 achievements and activities for the NUS Medicine portfolio.

## Features
- Ten structured achievement entries
- Category options based on the NUS Medicine sample CCA list
- Completeness and ready-for-review indicators
- Browser local-storage saving
- JSON backup export and CSV export
- Print / Save as PDF
- Final application checklist

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the default branch and `/ (root)`, then save.
5. Wait for GitHub Pages to finish deployment.

## Important
This is an organisation and preparation tool, not an official NUS website and not an admissions predictor. The ten category options are not mandatory categories. Check the official instructions for your application year and qualification before submitting. Data is stored in the current browser only; use the JSON export to make backups.
